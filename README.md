# Bryant Lake & Lawn website

A fast, static site for Bryant Lake & Lawn LLC (Rochester, IN). No build step: upload `index.html`, `styles.css`, `script.js` and the `images/` folder to any web host (GoDaddy cPanel `public_html`, Netlify, GitHub Pages).

## What's on it
- Full-screen aerial opening that zooms as you scroll, with quick Call / Text / Quote buttons and a live Lake Manitou conditions bar
- Statement text that lights up word by word as you read
- Services as stacking cards that slide over each other: docks & lifts, storage & service, lake services, lawn & property
- Authorized Floe dealer section
- Bryant Lift Trailer feature with the patented specs
- Pontoon rentals with pricing and a live 7-day "lake day" forecast for Lake Manitou and Nyona Lake
- Recent work gallery that scrolls sideways (swipe on phones)
- Why Bryant, contact cards for Brady and Gary, and a quote form
- Sticky Call / Text / Quote bar on phones

## Settings in `script.js`
- `SOCIAL`: paste Facebook, Instagram and TikTok links; the Follow Us section appears once at least one is set.
- `FORM_ENDPOINT`: optional form handler URL (e.g. Formspree). Without one, the form opens the visitor's email app addressed to lifttrailers@gmail.com with their request filled in.
